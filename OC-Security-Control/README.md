# OpenComputers Security Control

OC-SC is a modular security system using OpenComputers and OpenSecurity.

## Requirements


### Common

#### Mods

    - OpenComputers
    - OpenSecurity

#### Software / APIs / Components

    - Minitel
    - Tier 3 Data Card
    - Network Card (Wired or Wireless) or Linked Card

## Database Module

The Database module can store data using one of several formats

    - CBOR
    - JSON
    - OpenOS Serialization

The CBOR and JSON formats are provided by plugin modules. The OpenOS Serialization is a fallback used if neither of the plugins are installed.
